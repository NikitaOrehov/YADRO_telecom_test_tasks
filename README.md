# Тестовые задания

## Описание
Проект содержит два задания
 - Моделирование производственного цеха: последовательная обработка изделий
с динамическим распределением по станкам
 - Бот для исследования подземелья и сбора ресурсов

## Сборка

 - Склонируйте репозиторий:
     - git clone
 - Перейдите в папку с нужным проектом
 - Соберите его:
     - mkdir build && cd build
     - cmake ..
     - make
  
## Запуск

В папке build появится исполняемый файл. 
Запустите его с указанием пути до файла с входными данными.

Для задачи - Бот для исследования подземелья и сбора ресурсов: ./bot_Alica <путь до файла>

Для задачи - Моделирование производственного цеха: ./Manufactory <путь до файла>
